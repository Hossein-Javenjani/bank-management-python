# Bank Management System

یک برنامه‌ی خط فرمانی (CLI) ساده برای مدیریت حساب‌های بانکی، نوشته‌شده با پایتون و مفاهیم برنامه‌نویسی شی‌گرا (OOP).

## امکانات

- ایجاد حساب جدید (با جلوگیری از شماره حساب تکراری)
- واریز وجه
- برداشت وجه (با بررسی موجودی کافی)
- انتقال وجه بین دو حساب
- نمایش لیست حساب‌ها
- جستجوی حساب بر اساس نام صاحب حساب
- ذخیره و بارگذاری اطلاعات از فایل

## ساختار پروژه

bank-management-python/
│
├── main.py # نقطه ورود برنامه و منوی اصلی
├── account.py # کلاس Account (مدل داده)
├── bank.py # کلاس Bank (منطق مدیریت)
└── .gitignore

## نحوه اجرا

```bash
python main.py
```

## تکنولوژی‌ها

- Python 3
- برنامه‌نویسی شی‌گرا (OOP)
- Input validation با try/except
